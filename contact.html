Informations à préparer avant de nous contacter

Pour vous répondre rapidement et efficacement, merci de préparer les informations suivantes :

  • 1. Marque et modèle exact de votre smartphone (ex : iPhone 12, Samsung Galaxy S21)
  • 2. Type de réparation souhaité (écran, batterie, façade arrière)
  • 3. Description du problème (écran fissuré, batterie qui ne tient plus, etc.)
  • 4. Votre localisation (ville ou code postal)
  • 5. Vos disponibilités pour un rendez-vous

Astuce : Si vous avez déjà repéré une pièce détachée en ligne, vous pouvez nous communiquer le lien pour validation avant achat.
